# Q2.1 — Step 1: Prompt Normalisation

**Phase:** 2 — Input Processing  
**Depends on:** Q1.1  
**Required by:** Q2.2

---

## Goal

Produce a clean, embedding-ready string from the raw user query. This is a lightweight subset of the ETL normalisation (T3.1) — no HTML stripping, no entity decoding, but with added lowercasing and strict sentinel rejection via `ValueError`.

---

## Comparison with ETL `normalize_text`

| Behaviour | ETL `normalize_text` (T3.1) | Query `normalize_query` (Q2.1) |
|---|---|---|
| Strip HTML tags | Yes (rich-text editor output) | **No** (queries are plain text) |
| Decode HTML entities | Yes | **No** |
| Lowercase | No | **Yes** |
| Collapse whitespace | Yes | Yes |
| Unify punctuation | Yes | Yes |
| Sentinel handling | Return `None` | **Raise `ValueError`** |

The `PUNCT_MAP` constant from `etl/impl/transform/normalize.py` can be reused directly.

> **Refactor note:** `normalize_text` and `PUNCT_MAP` currently live in `etl/impl/transform/normalize.py`. Before implementing `normalize_query`, move `normalize_text` and `PUNCT_MAP` to `common/normalize.py` and update the ETL import. `normalize_query` then imports from `common/normalize.py` instead of reaching into `etl/`. This avoids a cross-module dependency from `query/` into `etl/`.

## Section A — `query/normalize.py`

```python
import re

from common.normalize import PUNCT_MAP

_SENTINELS = {"null", "undefined", "none"}


def normalize_query(query: str | None) -> str:
    if query is None:
        raise ValueError("query must not be None")
    text = query.strip()
    if not text or text.lower() in _SENTINELS:
        raise ValueError(f"invalid query: {query!r}")
    text = text.lower()
    text = text.translate(PUNCT_MAP)
    text = re.sub(r"\s+", " ", text).strip()
    return text
```

**Rules applied in order:**
1. Strip leading/trailing whitespace — reject if empty after strip
2. Reject sentinels (`"null"`, `"undefined"`, `"none"`) — case-insensitive check before lowercasing
3. Lowercase the whole string
4. Unify punctuation via `PUNCT_MAP` (curly quotes → straight, em/en dashes → `-`, `…` → `...`)
5. Collapse any remaining runs of whitespace to a single space

## Acceptance Tests

```python
import pytest
from query.normalize import normalize_query

# --- sentinel rejection ---
@pytest.mark.parametrize("bad", [None, "", "   ", "null", "NULL", "undefined", "none", "None"])
def test_sentinels_raise(bad):
    with pytest.raises(ValueError):
        normalize_query(bad)

# --- normalisation ---
def test_lowercase():
    assert normalize_query("Who Has Java Skills?") == "who has java skills?"

def test_trim_and_collapse_whitespace():
    assert normalize_query("  find   backend   devs  ") == "find backend devs"

def test_curly_quotes():
    assert normalize_query("who’s the best developer?") == "who's the best developer?"

def test_em_dash():
    assert normalize_query("senior—backend") == "senior-backend"

def test_combined():
    assert normalize_query("  Who Has “Java” Skills?  ") == 'who has "java" skills?'
```
