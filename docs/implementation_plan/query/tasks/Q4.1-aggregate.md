# Q4.1 — Step 4: Employee Aggregation & Scoring

**Phase:** 4 — Aggregation  
**Depends on:** Q3.1  
**Required by:** Q5.1

---

## Goal

Collapse the flat list of `ChunkHit` rows (one per chunk) into one `EmployeeHit` per employee: max score, deduplicated skills, and all chunk texts as evidence for the response step.

---

## Section A — `query/types.py` addition

Add `EmployeeHit` alongside the existing types:

```python
@dataclass
class EmployeeHit:
    employee_id: int
    score:       float       # max chunk score across all chunks for this employee
    skills:      list[str]   # deduplicated union of metadata["skills"] across all chunks
    chunks:      list[str]   # all chunk_text values, used as LLM evidence in Q5.2
```

---

## Section B — `query/aggregate.py`

### Implementation

```python
from query.types import ChunkHit, EmployeeHit


def aggregate(hits: list[ChunkHit]) -> list[EmployeeHit]:
    if not hits:
        return []

    grouped: dict[int, dict] = {}
    for hit in hits:
        eid = hit.employee_id
        if eid not in grouped:
            grouped[eid] = {"score": hit.score, "skills": set(), "chunks": []}
        entry = grouped[eid]
        entry["score"] = max(entry["score"], hit.score)
        entry["skills"].update(hit.metadata.get("skills", []))
        entry["chunks"].append(hit.chunk_text)

    return sorted(
        [
            EmployeeHit(
                employee_id=eid,
                score=entry["score"],
                skills=sorted(entry["skills"]),
                chunks=entry["chunks"],
            )
            for eid, entry in grouped.items()
        ],
        key=lambda e: e.score,
        reverse=True,
    )
```

**Notes:**
- Pure function — no DB calls, no side effects
- `skills` is built as a `set` during grouping to deduplicate, then converted to a sorted `list` for deterministic output
- `chunks` preserves insertion order (the order chunks were returned by pgvector, i.e. score descending within the employee)
- `score` is the **max** across all chunks, not the average — a single highly-relevant chunk is enough to surface an employee

## Acceptance Tests

```python
from query.aggregate import aggregate
from query.types import ChunkHit


def _hit(employee_id, score, skills, chunk_text="chunk"):
    return ChunkHit(
        employee_id=employee_id,
        chunk_text=chunk_text,
        metadata={"skills": skills},
        score=score,
    )


def test_empty_input():
    assert aggregate([]) == []


def test_single_employee_single_chunk():
    result = aggregate([_hit(1, 0.9, ["Java"])])
    assert len(result) == 1
    assert result[0].employee_id == 1
    assert result[0].score == 0.9
    assert result[0].skills == ["Java"]
    assert result[0].chunks == ["chunk"]


def test_max_score_selected():
    hits = [
        _hit(1, 0.6, ["Java"], "chunk-a"),
        _hit(1, 0.9, ["Python"], "chunk-b"),
        _hit(1, 0.7, ["Go"], "chunk-c"),
    ]
    result = aggregate(hits)
    assert result[0].score == 0.9


def test_skills_deduplicated():
    hits = [
        _hit(1, 0.8, ["Java", "Python"], "chunk-a"),
        _hit(1, 0.7, ["Python", "Go"], "chunk-b"),
    ]
    result = aggregate(hits)
    assert sorted(result[0].skills) == ["Go", "Java", "Python"]


def test_all_chunks_collected():
    hits = [
        _hit(1, 0.8, [], "first"),
        _hit(1, 0.7, [], "second"),
    ]
    result = aggregate(hits)
    assert result[0].chunks == ["first", "second"]


def test_sorted_by_score_descending():
    hits = [
        _hit(2, 0.6, []),
        _hit(1, 0.9, []),
        _hit(3, 0.75, []),
    ]
    result = aggregate(hits)
    assert [e.employee_id for e in result] == [1, 3, 2]


def test_multiple_employees_independent():
    hits = [
        _hit(1, 0.9, ["Java"]),
        _hit(2, 0.8, ["Python"]),
        _hit(1, 0.7, ["Go"]),
    ]
    result = aggregate(hits)
    emp1 = next(e for e in result if e.employee_id == 1)
    emp2 = next(e for e in result if e.employee_id == 2)
    assert emp1.score == 0.9
    assert emp2.score == 0.8
    assert "Go" in emp1.skills
    assert "Python" not in emp1.skills
```
