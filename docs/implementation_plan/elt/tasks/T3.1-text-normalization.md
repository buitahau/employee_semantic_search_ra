# T3.1 — Step 1: Text Normalization

**Phase:** 3 — Transform  
**Depends on:** T2.1  
**Required by:** T3.2

---

## Goal

Walk every text field in an `EmployeeData` (T2.1 output), clean each one, and return an `EmployeeData` where all text fields carry a consistent, HTML-free, whitespace-collapsed value — or `None` if the original was empty/sentinel.

This step is purely deterministic — no ML, no external calls.

---

## Data Flow

```
EmployeeData          normalize()          EmployeeData
─────────────────   ──────────────────────►  ────────────────────────
cv.cv (raw HTML)                             cv.cv (plain text | None)
cv.introduction                              cv.introduction
experience.description                       experience.description
experience.roles_and_responsibilities        experience.roles_and_responsibilities
...                                          ...
```

Non-text fields (`date_from`, `date_to`, `is_currently_working`, `skills`, `level`, `updated_at`) are copied through unchanged.

---

## Output Type: `EmployeeData`

Same class as the input — `normalize()` returns a new `EmployeeData` instance with text fields cleaned. No separate "Normalized" types. Dataclasses are defined in `common/types.py` (see T2.1).

## Top-Level Function

```python
def normalize(raw: EmployeeData) -> EmployeeData:
    return EmployeeData(
        employee_id=raw.employee_id,
        cv=_normalize_cv(raw.cv),
        experiences=[_normalize_experience(e) for e in raw.experiences],
        employment_histories=[_normalize_employment_history(h) for h in raw.employment_histories],
        trainings=[_normalize_training(t) for t in raw.trainings],
        tasks=[_normalize_task(t) for t in raw.tasks],
        skills=[_normalize_user_skill(s) for s in raw.skills],
    )
```

## Core Function: `normalize_text`

```python
def normalize_text(text: str | None) -> str | None:
    ...
```

- **Input:** raw text from any source field, or `None`
- **Output:** cleaned string, or `None` if the input is a sentinel / empty
- **Pure function** — no side effects, no I/O

### Processing Steps (applied in order)

#### 1. Sentinel check

Return `None` immediately if:

| Value | Type |
|---|---|
| `None` | Python `None` |
| `""` | empty string |
| `"null"` | literal string |
| `"undefined"` | literal string |
| `"None"` | literal string |

```python
SENTINELS = {"null", "undefined", "None"}

if text is None or text.strip() == "" or text.strip() in SENTINELS:
    return None
```

#### 2. Strip HTML tags

```python
import re
text = re.sub(r"<[^>]+>", " ", text)
```

| Input | Output |
|---|---|
| `"<p>Hello <b>world</b></p>"` | `" Hello  world "` |
| `"<br/>"` | `" "` |

#### 3. Decode HTML entities

```python
from html import unescape
text = unescape(text)
```

| Entity | Result |
|---|---|
| `&amp;` | `&` |
| `&rsquo;` | `'` |
| `&ldquo;` / `&rdquo;` | `"` |
| `&#46;` | `.` |
| `&nbsp;` | non-breaking space (collapsed in step 5) |

#### 4. Unify punctuation

```python
PUNCT_MAP = str.maketrans({
    "‘": "'",  # left single quotation mark
    "’": "'",  # right single quotation mark
    "“": '"',  # left double quotation mark
    "”": '"',  # right double quotation mark
    "–": "-",  # en dash
    "—": "-",  # em dash
    "…": "...",# ellipsis
})
text = text.translate(PUNCT_MAP)
```

#### 5. Collapse whitespace

```python
text = re.sub(r"[\s​‌‍﻿]+", " ", text).strip()
```

Collapsed: spaces, `\t`, `\n`, `\r`, zero-width space, zero-width non-joiner, zero-width joiner, BOM.

#### 6. Final empty check

```python
return text if text else None
```

### What NOT to Apply

| Operation | Reason |
|---|---|
| Lowercasing | Destroys case-sensitive names (`AWS`, `Vue.js`) |
| Stop-word removal | Removes meaningful context |
| Stemming / lemmatization | Breaks skill names and domain terms |
| Punctuation stripping | Removes separators in version strings (`v1.2.3`) |
| Spell correction | May silently corrupt technical terms |

### Full implementation

```python
import re
from html import unescape

SENTINELS = {"null", "undefined", "None"}

PUNCT_MAP = str.maketrans({
    "‘": "'", "’": "'",
    "“": '"', "”": '"',
    "–": "-", "—": "-",
    "…": "...",
})

def normalize_text(text: str | None) -> str | None:
    if text is None:
        return None
    stripped = text.strip()
    if stripped == "" or stripped in SENTINELS:
        return None
    text = re.sub(r"<[^>]+>", " ", text)
    text = unescape(text)
    text = text.translate(PUNCT_MAP)
    text = re.sub(r"[\s​‌‍﻿]+", " ", text).strip()
    return text if text else None
```

## Unit Tests

File: `tests/test_normalize.py`

```python
import pytest
from etl.transform import normalize_text, normalize
from common.types import EmployeeData, Cv, Experience

# --- normalize_text: sentinel cases ---

@pytest.mark.parametrize("value", [None, "", "   ", "null", "undefined", "None"])
def test_sentinels_return_none(value):
    assert normalize_text(value) is None

def test_html_only_returns_none():
    assert normalize_text("<br/>") is None

# --- normalize_text: transformations ---

def test_strips_html_tags():
    assert normalize_text("<p>Hello <b>world</b></p>") == "Hello world"

def test_decodes_amp():
    assert normalize_text("Vue.js &amp; Node.js") == "Vue.js & Node.js"

def test_decodes_rsquo():
    assert normalize_text("it&rsquo;s") == "it's"

def test_em_dash_to_hyphen():
    assert normalize_text("A—B") == "A-B"

def test_curly_quotes_to_straight():
    assert normalize_text("“Hello”") == '"Hello"'

def test_collapses_whitespace():
    assert normalize_text("Hello   world\n") == "Hello world"

def test_collapses_zero_width_chars():
    assert normalize_text("Hello​world") == "Hello world"

# --- normalize_text: preservation ---

def test_preserves_case():
    assert normalize_text("AWS Lambda") == "AWS Lambda"

def test_preserves_version_strings():
    assert normalize_text("Node.js v18.2.0") == "Node.js v18.2.0"

# --- normalize: EmployeeData → EmployeeData ---

def test_normalize_cv_fields(fixture_raw_employee):
    result = normalize(fixture_raw_employee)
    assert result.employee_id == fixture_raw_employee.employee_id
    # HTML stripped from cv text
    assert "<" not in (result.cv.cv or "")

def test_normalize_preserves_dates(fixture_raw_employee):
    result = normalize(fixture_raw_employee)
    for exp in result.experiences:
        assert exp.date_from == fixture_raw_employee.experiences[0].date_from

def test_normalize_preserves_skills_list(fixture_raw_employee):
    result = normalize(fixture_raw_employee)
    for exp in result.experiences:
        assert isinstance(exp.skills, list)

def test_normalize_empty_employee():
    raw = EmployeeData(
        employee_id=999,
        cv=None,
        experiences=[],
        employment_histories=[],
        trainings=[],
        tasks=[],
        skills=[],
    )
    result = normalize(raw)
    assert result.employee_id == 999
    assert result.cv is None
    assert result.experiences == []

def test_spec_example():
    from datetime import date, datetime
    raw = EmployeeData(
        employee_id=1,
        cv=Cv(
            cv="<p>Worked on <b>Vue.js&nbsp;&amp;&nbsp;Node.js</b> for 2 years.\r\nResponsible for​ API design &amp; implementation.</p>",
            custom_position=None,
            introduction=None,
            updated_at=datetime(2024, 1, 1),
        ),
        experiences=[], employment_histories=[],
        trainings=[], tasks=[], skills=[],
    )
    result = normalize(raw)
    assert result.cv.cv == "Worked on Vue.js & Node.js for 2 years. Responsible for API design & implementation."
```
