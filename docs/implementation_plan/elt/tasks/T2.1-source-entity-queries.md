# T2.1 — Source Entity Queries

**Phase:** 2 — Extract  
**Depends on:** T1.2  
**Required by:** T3.1

---

## Goal

Provide one typed query function per source entity and a top-level assembler (`get_employee_data`) that populates an `EmployeeData` DTO. A second function (`get_stale_employee_ids`) identifies employees whose source data has changed since their last index run.

All query functions must:
- Accept `employee_id: int`
- Use parameterised queries (no string interpolation)
- Return typed dataclasses (never raw tuples or dicts)

---

## Section 1 — `get_employee_data`

Calls T2.1a–T2.1f and assembles the results into a `EmployeeData` dataclass.

```python
def get_employee_data(employee_id: int) -> EmployeeData:
    return EmployeeData(
        employee_id=employee_id,
        cv=get_cv(employee_id),
        experiences=get_experiences(employee_id),
        employment_histories=get_employment_histories(employee_id),
        trainings=get_trainings(employee_id),
        tasks=get_tasks(employee_id),
        skills=get_user_skills(employee_id),
    )
```

- All list fields default to `[]` for an unknown employee — no exception raised.
- `cv` defaults to `None` for an unknown employee.

### T2.1a — CV

**Tables:** `user_cvs`, `cv_overview`  
**Returns:** `Cv | None`

```sql
SELECT
    uc.cv,
    co.custom_position,
    co.introduction,
    GREATEST(uc.updated_at, co.updated_at) AS updated_at
FROM user_cvs uc
LEFT JOIN cv_overview co ON co.user_cv_id = uc.id
WHERE uc.employee_id = %(employee_id)s
  AND uc.is_selected = true
LIMIT 1;
```

```sql
    e.domain,
    e.description,
    e.roles_and_responsibilities,
    e.date_from,
    e.date_to,
    e.is_currently_working,
    e.updated_at,
    COALESCE(
        array_agg(s.name) FILTER (WHERE s.name IS NOT NULL),
        '{}'

LEFT JOIN skills s ON s.id = es.skill_id
WHERE e.employee_id = %(employee_id)s
```

## Section 2 — `get_stale_employee_ids`

> **Note:** This feature is **low priority** and should be implemented after Section 1 is stable. It is required by the reconciliation job (T5.2) but not needed for the initial indexing pipeline (T4.1).

Returns `employee_id` values where at least one source-entity row has `updated_at > last_index_at` or `last_index_at IS NULL`. Excludes employees whose data has not changed since their last index run.

```python
def get_stale_employee_ids() -> list[int]:
    ...
```

### Query

Runs against the **traditional PostgreSQL DB** (`SOURCE_DB_*`).

```sql
SELECT DISTINCT employee_id
FROM (

    SELECT employee_id FROM user_cvs
    WHERE last_index_at IS NULL OR updated_at > last_index_at

    UNION

    SELECT employee_id FROM user_skills
    WHERE last_index_at IS NULL OR updated_at > last_index_at

    UNION

    SELECT employee_id FROM experiences
    WHERE last_index_at IS NULL OR updated_at > last_index_at

    UNION

    SELECT employee_id FROM experience_skills es
    JOIN experiences e ON e.id = es.experience_id
    WHERE es.last_index_at IS NULL OR es.updated_at > es.last_index_at

    UNION

    SELECT employee_id FROM employment_histories
    WHERE last_index_at IS NULL OR updated_at > last_index_at

    UNION

    SELECT employee_id FROM trainings
    WHERE last_index_at IS NULL OR updated_at > last_index_at

    UNION

    SELECT taa.employee_id
    FROM task_assignments_assignees taa
    WHERE taa.last_index_at IS NULL OR taa.updated_at > taa.last_index_at

    UNION

    SELECT taa.employee_id
    FROM task_assignments ta
    JOIN task_assignments_assignees taa ON taa.task_assignment_id = ta.id
    WHERE ta.last_index_at IS NULL OR ta.updated_at > ta.last_index_at

) stale
ORDER BY employee_id;
```

### Behaviour

| Scenario | Included? |
|---|---|
| `last_index_at IS NULL` on any row | Yes — never been indexed |
| `updated_at > last_index_at` on any row | Yes — changed since last index |
| All rows have `updated_at <= last_index_at` | No — up to date |
| Employee has no rows in any source table | No — nothing to index |

## Acceptance Test

```python
# Seed a known employee with at least one row in each source table.
# Assumes fixture data is loaded before running.

from query import get_employee_data, get_stale_employee_ids

FIXTURE_EMPLOYEE_ID = 1

def test_get_employee_data():
    data = get_employee_data(FIXTURE_EMPLOYEE_ID)
    assert data.employee_id == FIXTURE_EMPLOYEE_ID
    assert data.cv is not None
    assert len(data.experiences) > 0
    assert len(data.skills) > 0
    # All skills in experiences are lists of strings
    for exp in data.experiences:
        assert isinstance(exp.skills, list)

def test_unknown_employee_returns_empty():
    data = get_employee_data(employee_id=999999)
    assert data.cv is None
    assert data.experiences == []
    assert data.employment_histories == []
    assert data.trainings == []
    assert data.tasks == []
    assert data.skills == []

def test_get_stale_employee_ids_includes_unindexed():
    # Fixture employee has last_index_at = NULL → must appear in stale list
    stale = get_stale_employee_ids()
    assert FIXTURE_EMPLOYEE_ID in stale

def test_get_stale_employee_ids_excludes_up_to_date(db_conn):
    # After setting last_index_at = NOW() on all rows for the fixture employee,
    # they must no longer appear in the stale list.
    db_conn.execute(
        "UPDATE user_cvs SET last_index_at = NOW() WHERE employee_id = %s",
        (FIXTURE_EMPLOYEE_ID,),
    )
    # ... repeat for all source tables ...
    stale = get_stale_employee_ids()
    assert FIXTURE_EMPLOYEE_ID not in stale
```
