# T3.5 — Step 5: Embedding

**Phase:** 3 — Transform
**Depends on:** T3.4
**Required by:** T3.6 (transform coordinator), T4.1 (load)

---

## Goal

For every `ChunkRecord` produced by T3.4, compute a 384-dimensional L2-normalised embedding vector using the `all-MiniLM-L6-v2` ONNX model and write it to `ChunkRecord.embedding`. After this step every chunk is fully populated and ready for the load phase.

The step is split into three files inside `etl/impl/transform/embedding/`:

- **`model.py`** — lazy ONNX session singleton
- **`encoder.py`** — tokenize → infer → pool → normalize; public `embed()` function
- **`__init__.py`** — `embed_chunks()` orchestrator over `EmployeeData`

`etl/transform.py` calls `embed_chunks()` after `chunking()`.

---

## Data Flow

```
EmployeeData with entity.chunks = list[ChunkRecord] (embedding=None)
       ↓ embed_chunks()
for each entity → for each ChunkRecord:
    chunk.embedding = embed(chunk.chunk_text)
       ↓
EmployeeData with entity.chunks = list[ChunkRecord] (embedding=list[float], len=384)
```

## Section 1 — ONNX Session (`model.py`)

Load the ONNX runtime inference session once, lazily, from `settings.embedding_model_path`.

### Contract

| Detail | Value |
|---|---|
| Model file | `settings.embedding_model_path` (env: `EMBEDDING_MODEL_PATH`) |
| Runtime | `onnxruntime.InferenceSession` (CPU provider) |
| Initialisation | Lazy singleton — created once on first call, reused on all subsequent calls |
| Thread safety | Session is read-only after creation; safe for concurrent inference |

---

## Section 2 — Encoder (`encoder.py`)

### `_tokenize(text: str)`

Tokenize a single string for ONNX inference. Uses the same `tokenizer.json` as the chunking phase (loaded via `_get_tokenizer()` from `chunking/tokenizer.py`), but called with padding and truncation enabled so the output includes an attention mask.

| Detail | Value |
|---|---|
| Padding | To the longest sequence in the batch (single-item batch: pad to model max or sequence length) |
| Truncation | At 512 tokens (BERT limit) |
| Returns | `input_ids`, `attention_mask`, `token_type_ids` — each as `int64` numpy arrays of shape `(1, seq_len)` |

### `_mean_pool(token_embeddings, attention_mask)`

Compute a single sentence vector from per-token vectors by averaging only non-padding tokens.

- Expand `attention_mask` to shape `(1, seq_len, 384)` so it broadcasts against `token_embeddings`.
- Sum the masked token embeddings along the sequence dimension.
- Divide by the number of non-padding tokens (sum of `attention_mask`, clamped to ≥ 1 to avoid division by zero).
- Result shape: `(1, 384)`.

### `_l2_normalize(vector)`

Divide the pooled vector by its L2 norm. Result has norm `1.0 ± 1e-6`.

### `embed(text: str) -> list[float]`

Public function. Chains `_tokenize → session inference → _mean_pool → _l2_normalize`. Returns a Python `list[float]` of length 384.

### Contract

| Detail | Value |
|---|---|
| Input | Any non-empty string |
| Output | `list[float]`, length 384, L2 norm `1.0 ± 1e-6` |
| ONNX inputs | `input_ids`, `attention_mask`, `token_type_ids` (all `int64`, shape `(1, seq_len)`) |
| ONNX output used | `last_hidden_state` — shape `(1, seq_len, 384)` |
| Pooling | Mean over non-padding tokens (attention mask weighted) |
| Normalisation | L2 (unit norm) |

---

## Section 3 — Orchestrator (`__init__.py`)

### `embed_chunks(data: EmployeeData) -> EmployeeData`

Iterate all six entity types on `EmployeeData`. For each entity, iterate its `chunks` list and call `embed(chunk.chunk_text)`, writing the result to `chunk.embedding`. Returns the same `EmployeeData` object (mutated in place).

Entities without chunks (empty `chunks` list) are skipped silently.

### Contract

| Detail | Value |
|---|---|
| Input / output | `EmployeeData` → `EmployeeData` (mutates `chunk.embedding` in place) |
| Entities processed | `cv`, `experiences`, `employment_histories`, `trainings`, `tasks`, `skills` |
| Chunks with no text | `embed()` is still called — `chunk_text` is never empty after T3.4 |
| After this step | Every `ChunkRecord.embedding` is a `list[float]` of length 384; no chunk has `embedding=None` |

---

## `etl/transform.py` Integration

`embed_chunks()` is called as the fifth transform phase, after `chunking()`. The commented stub `# data = embed(data)` is replaced with `data = embed_chunks(data)`.

## Unit Tests

File: `tests/test_embedding.py`

### Encoder — pure numeric tests (no model file required)

- `_mean_pool`: all-ones mask → result equals plain mean of token vectors
- `_mean_pool`: mask with some zeros → padding tokens do not contribute
- `_l2_normalize`: output norm is `1.0 ± 1e-6`
- `_l2_normalize`: zero vector → handled without division-by-zero error

### `embed` — model integration tests

- Same string embedded twice → cosine similarity = `1.0` (deterministic output)
- Output length is exactly 384
- Output norm is `1.0 ± 1e-6`
- ONNX output per-dimension delta vs `sentence-transformers` reference < `1e-5`

### Orchestrator

- `embed_chunks` fills `chunk.embedding` on every chunk for all six entity types
- Entity with empty `chunks` list → no error, entity unchanged
- After `embed_chunks`, no `ChunkRecord` has `embedding=None`
