# T3.4 — Step 4: Chunking

**Phase:** 3 — Transform
**Depends on:** T3.3
**Required by:** T3.5

---

## Goal

For each entity in `EmployeeData`, split its combined text fields into overlapping sentence-window chunks (≤ 250 tokens for cv/experience, ≤ 200 for others), and store the resulting token counts, sentence spans, and windows in the entity's `pipeline_state` dict. `ChunkRecord` assembly (adding prefix, provenance, and embedding) is deferred to T3.6.

The task is split into four sections, each in its own file inside `etl/impl/transform/chunking/`:
- **Section 1** — `tokenizer.py` — load once; count tokens per text fragment
- **Section 2** — `splitter.py` — break text into spans with character positions
- **Section 3** — `accumulator.py` — build windows ≤ `tokens_max` with ≥ 40-token overlap
- **Section 4** — `chunking/__init__.py` — three-pass orchestrator over `EmployeeData`

`etl/transform.py` (the transform coordinator) calls `chunking()` from `etl.impl.transform.chunking`.

## Section 1 — Tokenizer

**File:** `etl/impl/transform/chunking/tokenizer.py`

Load the `all-MiniLM-L6-v2` tokenizer once, lazily, from the same directory as `EMBEDDING_MODEL_PATH`.

```python
from pathlib import Path
from tokenizers import Tokenizer
from common.config import settings

_tokenizer: Tokenizer | None = None


def _get_tokenizer() -> Tokenizer:
    global _tokenizer
    if _tokenizer is None:
        model_dir = Path(settings.embedding_model_path).parent
        _tokenizer = Tokenizer.from_file(str(model_dir / "tokenizer.json"))
    return _tokenizer


def _count_tokens(text: str) -> int:
    return len(_get_tokenizer().encode(text).ids)
```

### Contract

| Detail | Value |
|---|---|
| File loaded | `{parent(EMBEDDING_MODEL_PATH)}/tokenizer.json` |
| Library | `tokenizers` (HuggingFace fast tokenizer) |
| Initialisation | Lazy singleton — loaded once, reused on all subsequent calls |
| `_count_tokens` | Returns number of token IDs for the given string |

### Example

`all-MiniLM-L6-v2` uses a BERT WordPiece tokenizer (lowercase). Token counts below are approximate — actual values depend on the model vocabulary.

```python
_count_tokens("python")
# → 1   ("python" is a single known token)

_count_tokens("FastAPI")
# → 3   lowercased "fastapi" → ["fast", "##ap", "##i"]

_count_tokens("PostgreSQL")
# → 4   "postgresql" → ["post", "##gre", "##s", "##ql"] or similar

_count_tokens("Experience: ")
# → 2   ["experience", ":"]  (whitespace is not a separate token)

_count_tokens("Experience: Built REST APIs using FastAPI.")
# → 10  prefix (2) + content words + subwords
```

> `_count_tokens` is called once per entity to compute `pipeline_state["token_count"]` and once per emitted window to compute the 4th element of the `(text, char_start, char_end, token_count)` tuple.

## Section 2 — Sentence Splitter

**File:** `etl/impl/transform/chunking/splitter.py`

Split `text` into sentence spans. A boundary is `.`, `!`, or `?` followed by one or more whitespace characters.

```python
import re

_SENT_BOUNDARY = re.compile(r'(?<=[.!?])\s+')


def _split_sentences(text: str) -> list[tuple[str, int, int]]:
    """Returns [(sentence_text, char_start, char_end), ...]."""
    if not text or not text.strip():
        return []
    sentences = []
    pos = 0
    for m in _SENT_BOUNDARY.finditer(text):
        span = text[pos : m.start() + 1].strip()
        if span:
            sentences.append((span, pos, m.start() + 1))
        pos = m.end()
    tail = text[pos:].strip()
    if tail:
        sentences.append((tail, pos, len(text)))
    return sentences
```

### Contract

| Detail | Value |
|---|---|
| Boundary | `.`, `!`, or `?` followed by `\s+` (lookbehind) |
| Empty / whitespace-only input | Returns `[]` |
| No boundaries | Returns one tuple covering the entire stripped text |
| `char_start` / `char_end` | Offsets into the original `text`; `char_end` is exclusive |
| Sentence string | Leading/trailing whitespace stripped |

### Examples

| Input | Output (sentence strings only) |
|---|---|
| `"First. Second. Third."` | `["First.", "Second.", "Third."]` |
| `"No boundary"` | `["No boundary"]` |
| `"Really! Sure? Yes."` | `["Really!", "Sure?", "Yes."]` |
| `""` | `[]` |

### Example — full output with character positions

```python
text = (
    "Developed REST APIs using FastAPI. "   # 35 chars (positions  0–34, space at 34)
    "Managed PostgreSQL databases. "        # 30 chars (positions 35–64, space at 64)
    "Deployed microservices on AWS."        # 30 chars (positions 65–94)
)
# len(text) = 95

_split_sentences(text)
# [
#   ("Developed REST APIs using FastAPI.", 0,  35),
#   ("Managed PostgreSQL databases.",      35, 65),
#   ("Deployed microservices on AWS.",     65, 95),
# ]
```

How positions are derived:

| # | Regex match | `m.start()` | `m.start()+1` | `sentence` | `char_start` | `char_end` |
|---|---|---|---|---|---|---|
| 0 | space after `.` at pos 34 | 34 | 35 | `"Developed REST APIs using FastAPI."` | 0 | 35 |
| 1 | space after `.` at pos 64 | 64 | 65 | `"Managed PostgreSQL databases."` | 35 | 65 |
| 2 | tail (no match after last `.`) | — | — | `"Deployed microservices on AWS."` | 65 | 95 |

> `text[char_start : char_end].strip() == sentence` holds for every row.  
> Adjacent sentences share their boundary: sentence 0's `char_end` (35) equals sentence 1's `char_start` (35).

## Section 3 — Greedy Window Accumulator

**File:** `etl/impl/transform/chunking/accumulator.py`

Accumulate sentences into windows respecting per-source-type token limits, with ≥ `OVERLAP_MIN` token overlap between consecutive windows. The token budget (`tokens_max`) is passed in from the orchestrator so that richer source types (cv, experience) can use a larger window.

```python
from typing import Callable
from .tokenizer import _count_tokens as _default_count_tokens, _get_tokenizer

TOKENS_MAX = 250   # default fallback
OVERLAP_MIN = 40
```

### `_accumulate_windows`

```python
def _accumulate_windows(
    sentences: list[tuple[str, int, int]],
    prefix: str,
    tokens_max: int = TOKENS_MAX,
    count_fn: Callable[[str], int] | None = None,
) -> list[tuple[str, int, int, int]]:
    """
    Returns [(window_text, char_start, char_end, token_count), ...].

    tokens_max: per-source-type budget passed from chunking().
    count_fn defaults to None. When None, _default_count_tokens is used at call
    time so that unittest.mock.patch on the tokenizer module takes effect.
    """
    fn = count_fn if count_fn is not None else _default_count_tokens
    ...
```

### Algorithm

```
current: list[(text, char_start, char_end)] = []

for each sentence s (text, start, end):
    if fn(s.text) > tokens_max:
        # single sentence too long — flush current, delegate to fallback
        if current:
            emit_window(current)
            current = []
        for sub in _token_window_split(s.text, char_offset=s.start, max_tokens=tokens_max):
            emit_window([sub])
        continue

    candidate = prefix + join_sentences(current + [s])
    if fn(candidate) > tokens_max and current is non-empty:
        emit_window(current)
        current = _build_overlap(current, fn)

    current.append(s)

if current:
    emit_window(current)
```

**`_build_overlap`** — prefer semantic continuity over a hard token cap:

```
Walk current backwards, inserting sentences at the front of `overlap`:
  overlap = []
  total   = 0

  for s in reversed(current):
      overlap.insert(0, s)
      total += fn(s.text)
      if total >= OVERLAP_MIN:
          break          ← reached target; stop adding

  return overlap         ← always contains ≥ 1 sentence
```

Key behaviours:
- **Short last sentence** (e.g. 8 tokens): keeps going backwards until total ≥ `OVERLAP_MIN`. If the last sentence is 8 tokens and the previous is 60, the overlap will be 68 tokens — slightly over the old `OVERLAP_MAX` but semantically complete.
- **All sentences short** (cumulative total < `OVERLAP_MIN`): returns all of `current`; no context is lost.
- **Minimum guarantee**: the loop always adds at least `current[-1]`, so the overlap is never empty.

**Emitting a window:**
- `window_text = " ".join(text for text, _, _ in current)`
- `char_start = current[0][1]`
- `char_end   = current[-1][2]`

### Fallback: `_token_window_split`

When a single sentence exceeds `TOKENS_MAX` tokens, split it into fixed token windows using the tokenizer's character-offset map.

```python
from .tokenizer import _get_tokenizer

def _token_window_split(
    text: str,
    char_offset: int = 0,
    max_tokens: int = TOKENS_MAX,
    overlap_tokens: int = OVERLAP_MIN,
) -> list[tuple[str, int, int]]:
    enc = _get_tokenizer().encode(text)
    ids = enc.ids
    offsets = enc.offsets    # list[(char_start, char_end)] per token, relative to text
    step = max_tokens - overlap_tokens
    windows = []
    i = 0
    while i < len(ids):
        end = min(i + max_tokens, len(ids))
        t_start = offsets[i][0]
        t_end   = offsets[end - 1][1]
        windows.append((text[t_start:t_end], char_offset + t_start, char_offset + t_end))
        if end == len(ids):
            break
        i += step
    return windows
```

### Contract

| Detail | Value |
|---|---|
| `TOKENS_MAX` | 250 — default fallback constant in `accumulator.py` |
| `tokens_max` param | Per-call budget passed from `chunking()`; all source types currently use `TOKENS_MAX` (250) for cv/experience, 200 for others |
| `OVERLAP_MIN` | 40 tokens — minimum target for the overlap region |
| Return type | `list[tuple[str, int, int, int]]` — `(window_text, char_start, char_end, token_count)` |
| Single sentence ≤ `tokens_max` | Produces one window; no overlap |
| Overlap guarantee | `char_start` of window N+1 ≤ `char_end` of window N |
| Overlap semantics | Walk backwards until cumulative ≥ `OVERLAP_MIN`; always ≥ 1 sentence; no hard upper cap — short last sentences pull in additional context |
| Long-sentence fallback | `_token_window_split` uses tokenizer `Encoding.offsets` for exact character positions |
| `count_fn` | `None` defaults to `_default_count_tokens` via runtime lookup |

### Example — normal case (≥ OVERLAP_MIN reached after one sentence)

**Setup**: 4 sentences, mock counter 60 tokens/sentence, prefix `"Experience: "` costs 5 tokens, `tokens_max = 200`.

```
sentences = [
    ("Developed REST APIs using FastAPI.", 0,   35),   # s0  60 tok
    ("Managed PostgreSQL databases.",      35,  65),   # s1  60 tok
    ("Led the frontend team with Vue.js.", 65,  100),  # s2  60 tok
    ("Deployed microservices on AWS.",     100, 130),  # s3  60 tok
]
```

```
current = []

s0: fn("Experience: Developed REST APIs using FastAPI.")
    = 5 + 60 = 65 ≤ 200  →  current = [s0]

s1: fn("Experience: … FastAPI. Managed … databases.")
    = 5 + 120 = 125 ≤ 200  →  current = [s0, s1]

s2: fn("Experience: … databases. Led … Vue.js.")
    = 5 + 180 = 185 ≤ 200  →  current = [s0, s1, s2]

s3: fn("Experience: … Vue.js. Deployed … AWS.")
    = 5 + 240 = 245 > 200  →  EMIT window from [s0, s1, s2]

    ── emit window 0 ──────────────────────────────────────────
    window_text = "Developed … FastAPI. Managed … databases. Led … Vue.js."
    char_start  = 0,  char_end = 100
    ────────────────────────────────────────────────────────────

    _build_overlap([s0, s1, s2]):
      s2 = 60 ≥ OVERLAP_MIN (40)  →  stop after first iteration
      overlap = [s2]  (60 tokens)

    current = [s2, s3]

(end)  →  EMIT window 1

    ── emit window 1 ──────────────────────────────────────────
    window_text = "Led … Vue.js. Deployed … AWS."
    char_start  = 65,  char_end = 130
    ────────────────────────────────────────────────────────────
```

`s2.char_start` (65) < window 0's `char_end` (100) — overlap confirmed.

### Example — short last sentence (improved overlap behaviour)

**Setup**: same prefix/limit, but `s2` is very short (8 tokens).

```
sentences = [
    ("Led the team and defined the architecture.",  0,   44),   # s0  70 tok
    ("Coordinated with three external vendors.",    45,  85),   # s1  60 tok
    ("Well done.",                                  86,  96),   # s2   8 tok  ← short
    ("Deployed to production in Q4.",               97, 128),   # s3  60 tok
]
tokens_max = 200
```

```
current = []

s0: 5+70 = 75 ≤ 200  →  current = [s0]
s1: 5+130 = 135 ≤ 200  →  current = [s0, s1]
s2: 5+138 = 143 ≤ 200  →  current = [s0, s1, s2]
s3: 5+198 = 203 > 200  →  EMIT window from [s0, s1, s2]

    _build_overlap([s0, s1, s2]):
      iter 1: add s2  →  total = 8   < 40  →  continue
      iter 2: add s1  →  total = 68  ≥ 40  →  stop
      overlap = [s1, s2]  (68 tokens)

    (Old rule would have stopped at s2 = 8 tokens — too little context.
     New rule keeps going until ≥ OVERLAP_MIN regardless of the upper cap.)

    current = [s1, s2, s3]  (5+128 = 133 ≤ 200)

(end)  →  EMIT window 1

    ── emit window 1 ──────────────────────────────────────────
    window_text = "Coordinated … vendors. Well done. Deployed … Q4."
    char_start  = 45  (s1.char_start < window 0 char_end=96  ✓ overlap)
    char_end    = 128
    ────────────────────────────────────────────────────────────
```

`s1` and `s2` both appear in window 0 and window 1 — the 8-token sentence alone would have given too little context; the improved rule pulls in its predecessor.

## Section 4 — `chunking` Orchestrator

**File:** `etl/impl/transform/chunking/__init__.py`

The orchestrator operates on the full `EmployeeData` object, filling `pipeline_state` on each entity in three passes: token counts, sentences, then windows.

```python
from common.types import EmployeeData
from etl.impl.transform.chunking.tokenizer import _count_tokens
from etl.impl.transform.chunking.splitter import _split_sentences
from etl.impl.transform.chunking.accumulator import _accumulate_windows, TOKENS_MAX


def _join(*values: str | None) -> str:
    return " ".join(v for v in values if v)


_PREFIX_BY_SOURCE: dict[str, str] = {
    "cv": "CV: ",
    "experience": "Experience: ",
    "employment_history": "Employment: ",
    "training": "Training: ",
    "task": "Task: ",
    "user_skill": "Skill: ",
}

_TOKENS_MAX_BY_SOURCE: dict[str, int] = {
    "cv": TOKENS_MAX,          # 250
    "experience": TOKENS_MAX,  # 250
    "employment_history": 200,
    "training": 200,
    "task": 200,
    "user_skill": 200,
}


def _fill_token_counts(data: EmployeeData) -> EmployeeData:
    """Pass 1: store raw token count for each entity's combined text."""
    if data.cv:
        text = _join(data.cv.cv, data.cv.custom_position, data.cv.introduction)
        data.cv.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    for exp in data.experiences:
        text = _join(exp.project_name, exp.domain, exp.description, exp.roles_and_responsibilities)
        exp.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    for hist in data.employment_histories:
        text = _join(hist.company)
        hist.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    for training in data.trainings:
        text = _join(training.training_title, training.training_description, training.topic_label, training.level_label)
        training.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    for task in data.tasks:
        text = _join(task.title, task.details, task.category_label)
        task.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    for skill in data.skills:
        text = _join(skill.skill_name)
        skill.pipeline_state["token_count"] = _count_tokens(text) if text else 0
    return data


def _fill_sentences(data: EmployeeData) -> EmployeeData:
    """Pass 2: split each entity's combined text into sentence spans."""
    if data.cv:
        text = _join(data.cv.cv, data.cv.custom_position, data.cv.introduction)
        if text:
            data.cv.pipeline_state["sentences"] = _split_sentences(text)
    for exp in data.experiences:
        text = _join(exp.project_name, exp.domain, exp.description, exp.roles_and_responsibilities)
        if text:
            exp.pipeline_state["sentences"] = _split_sentences(text)
    for hist in data.employment_histories:
        text = _join(hist.company)
        if text:
            hist.pipeline_state["sentences"] = _split_sentences(text)
    for training in data.trainings:
        text = _join(training.training_title, training.training_description, training.topic_label, training.level_label)
        if text:
            training.pipeline_state["sentences"] = _split_sentences(text)
    for task in data.tasks:
        text = _join(task.title, task.details, task.category_label)
        if text:
            task.pipeline_state["sentences"] = _split_sentences(text)
    for skill in data.skills:
        text = _join(skill.skill_name)
        if text:
            skill.pipeline_state["sentences"] = _split_sentences(text)
    return data


def _fill_windows(data: EmployeeData) -> EmployeeData:
    """Pass 3: accumulate sentence spans into overlapping token windows."""
    if data.cv:
        sentences = data.cv.pipeline_state.get("sentences", [])
        if sentences:
            data.cv.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["cv"], tokens_max=_TOKENS_MAX_BY_SOURCE["cv"],
            )
    for exp in data.experiences:
        sentences = exp.pipeline_state.get("sentences", [])
        if sentences:
            exp.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["experience"], tokens_max=_TOKENS_MAX_BY_SOURCE["experience"],
            )
    for hist in data.employment_histories:
        sentences = hist.pipeline_state.get("sentences", [])
        if sentences:
            hist.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["employment_history"], tokens_max=_TOKENS_MAX_BY_SOURCE["employment_history"],
            )
    for training in data.trainings:
        sentences = training.pipeline_state.get("sentences", [])
        if sentences:
            training.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["training"], tokens_max=_TOKENS_MAX_BY_SOURCE["training"],
            )
    for task in data.tasks:
        sentences = task.pipeline_state.get("sentences", [])
        if sentences:
            task.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["task"], tokens_max=_TOKENS_MAX_BY_SOURCE["task"],
            )
    for skill in data.skills:
        sentences = skill.pipeline_state.get("sentences", [])
        if sentences:
            skill.pipeline_state["windows"] = _accumulate_windows(
                sentences, prefix=_PREFIX_BY_SOURCE["user_skill"], tokens_max=_TOKENS_MAX_BY_SOURCE["user_skill"],
            )
    return data


def chunking(data: EmployeeData) -> EmployeeData:
    data = _fill_token_counts(data)
    data = _fill_sentences(data)
    data = _fill_windows(data)
    return data
```

### Contract

| Detail | Value |
|---|---|
| Input / output | `EmployeeData` → `EmployeeData` (mutates `pipeline_state` in place) |
| `pipeline_state["token_count"]` | Raw token count of the entity's combined text fields |
| `pipeline_state["sentences"]` | `list[tuple[str, int, int]]` from `_split_sentences` |
| `pipeline_state["windows"]` | `list[tuple[str, int, int, int]]` — `(text, char_start, char_end, token_count)` |
| Entity with no text | `pipeline_state` left without `"sentences"` / `"windows"` keys |
| `_PREFIX_BY_SOURCE` | Maps source type to prefix string (e.g. `"cv"` → `"CV: "`) |
| `_TOKENS_MAX_BY_SOURCE` | `cv`/`experience` → `TOKENS_MAX` (250); others → 200 |
| `ChunkRecord` assembly | Deferred to T3.6; T3.4 only populates `pipeline_state` |

### Usage (called from `etl/transform.py`)

```python
from etl.impl.transform.chunking import chunking

data = chunking(data)
# data.cv.pipeline_state["token_count"]  → int
# data.cv.pipeline_state["sentences"]    → list[tuple[str, int, int]]
# data.cv.pipeline_state["windows"]      → list[tuple[str, int, int, int]]
# (same for data.experiences[i], data.trainings[i], etc.)
```

def test_split_sentences_basic():
    result = _split_sentences("First sentence. Second sentence. Third.")

    # 4 sentences × 60 tokens + 5 prefix → 3 sentences = 185 ≤ 200, 4 = 245 > 200
    sentences = [
        (f"Sentence {i}.", i * 20, i * 20 + 18) for i in range(4)
    ]

        prefix = 5 if any(text.startswith(p) for p in ["CV: ", "Experience: "]) else 0
        return prefix + 60 * max(text.count("Sentence"), 1)

    ]

        return prefix + 60 * max(text.count("Sentence"), 1)

    windows_200 = _accumulate_windows(sentences, prefix="CV: ", tokens_max=200, count_fn=counter)
    windows_150 = _accumulate_windows(sentences, prefix="CV: ", tokens_max=150, count_fn=counter)
    assert len(windows_150) >= len(windows_200)


def test_accumulate_overlap_property():
    sentences = [
        (f"Sentence {i} ends here.", i * 30, i * 30 + 22) for i in range(8)
    ]
    def counter(text: str) -> int:
        prefix = 5 if text.startswith("CV: ") else 0
        return prefix + 50 * max(text.count("Sentence"), 1)

    windows = _accumulate_windows(sentences, prefix="CV: ", count_fn=counter)
    if len(windows) > 1:
        for i in range(len(windows) - 1):
            _, _, end_i = windows[i]
            _, start_next, _ = windows[i + 1]
            assert start_next < end_i, (
                f"Window {i+1} char_start ({start_next}) is not before "
                f"window {i} char_end ({end_i}) — no overlap"
            )


def test_accumulate_short_last_sentence_pulls_previous():
    # s2 is only 8 tokens; overlap should include s1 (60 tok) to reach OVERLAP_MIN
    sentences = [
        ("Sentence zero long text.", 0,  25),    # s0: 70 tok
        ("Sentence one long text.",  26, 51),    # s1: 60 tok
        ("Done.",                    52, 57),    # s2:  8 tok
        ("Sentence three text.",     58, 78),    # s3: 60 tok
    ]
    def counter(text: str) -> int:
        if "zero" in text: return 70
        if "one"  in text: return 60
        if "Done" in text: return 8
        if "three" in text: return 60
        # prefix-only or combined
        n = text.count("Sentence")
        done = 8 if "Done" in text else 0
        return 5 + 70 * ("zero" in text) + 60 * ("one" in text) + done + 60 * ("three" in text)

    def simple_counter(text: str) -> int:
        tokens = 0
        if "zero"  in text: tokens += 70
        if "one"   in text: tokens += 60
        if "Done"  in text: tokens += 8
        if "three" in text: tokens += 60
        if text.startswith("CV: "): tokens += 5
        return max(tokens, 1)

    windows = _accumulate_windows(sentences, prefix="CV: ", tokens_max=200, count_fn=simple_counter)
    if len(windows) > 1:
        # The overlap region must start at s1 (char_start=26), not s2 (char_start=52)
        # because s2 alone (8 tokens) is below OVERLAP_MIN
        assert windows[1][1] <= 26, (
            f"Expected overlap to include s1 (char_start=26); got {windows[1][1]}"
        )


def test_accumulate_empty_sentences():
    windows = _accumulate_windows([], prefix="CV: ", count_fn=lambda t: 10)
    assert windows == []
